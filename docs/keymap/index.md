# Refined Industry Compatible

Refined Industry Compatible 保留 Blender 自己的操作核心，再吸收其他 DCC 的操作核心。它不是一套要求用户重新学习的快捷键，而是让两种成熟习惯自然并存。

## 保留 Blender 的核心

Blender 已经高效而深入人心的操作继续保留。

- 视图导航仍然可以围绕 `MMB` 完成
- Transform 仍然保留 `G / S / R` 的操作逻辑
- Mode、Pie Menu 和上下文操作仍然保持 Blender 的特点

熟悉 Blender 的用户不必放弃原来的肌肉记忆。

## 吸收其他 DCC 的核心

同一类操作增加其他 DCC 用户熟悉的入口。

- 可以使用 `ALT + LMB / MMB / RMB` 导航视图
- 可以使用 `W / E / R` 控制 Transform 工具
- 选择、聚焦、组件层级和内容添加采用更通用的操作习惯

来自其他 DCC 的用户可以直接带着已有经验进入 Blender。

## 取长补短

两种方式并存，不互相取代。它既降低了跨软件切换的成本，也没有为了兼容其他 DCC 而牺牲 Blender 原本的优势。
