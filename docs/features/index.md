# 实用功能

O General 除了工作区、Preferences 和快捷键，还包含一组小而直接的功能。它们只在 Application Template 激活期间注册；切换到其他模板后，相关 Operator、Panel 和 Keymap 会注销。

<div class="grid cards" markdown>

-   :material-camera:{ .lg .middle } **Camera Bookmark**

    ---

    保存、预览、更新和恢复相机视角，数据随 `.blend` 文件保存。

    [使用 Camera Bookmark](camera-bookmark.md)

-   :material-content-paste:{ .lg .middle } **粘贴剪贴板图片**

    ---

    在 3D View、Node Editor 和绘制模式中直接粘贴图片，并自动 Pack 到工程。

    [粘贴图片](clipboard-image.md)

-   :material-ghost:{ .lg .middle } **Toggle Phantom**

    ---

    临时把对象变成便于观察和穿透选择的半透明状态，再次执行即可恢复。

    [切换 Phantom](toggle-phantom.md)

-   :material-cloud-download:{ .lg .middle } **OmooLab 在线内容**

    ---

    自动补充 OmooLab Extensions；Blender 5.2 还可使用 Remote Asset Library。

    [在线内容](online-content.md)

</div>
