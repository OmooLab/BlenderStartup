    设计原则

    取长补短

    优先保留 Blender 中已经高效、已经形成肌肉记忆的操作；再用其他 DCC 的通用做法补足迁移和一致性问题。

    意图一致

    相同按键在不同编辑器中尽量表达相近的意图。例如 F 用于聚焦，Tab 用于添加或进入当前工作上下文，Shift+Tab 用于吸附。

    为上下文而设计

    Blender 的核心能力来自 Mode、Editor 和 Tool Context。快捷键可以随上下文变化，但变化必须可预测，不能只追求给每个 Operator 分配一个唯一按键。

    点击与拖动都可以承载语义

    按键不仅有“按下”。点击、松开、双击和拖动可以将相关操作组织在同一入口，例如：

    • 点击 Tab：添加内容
    • 拖动 Tab：打开 Object Mode Pie
    • 单击 F：聚焦所选
    • 双击 F：查看全部

    高频操作优先

    最容易触及的按键留给高频、跨编辑器的操作；较少使用或具有破坏性的操作使用修饰键、双击或菜单。

    以 Blender Default 为事实基线

    文档中的“修改、新增、移除”只表示相对同版本 Blender Default 的差异。Industry Compatible 是设计参考和迁移目标，不是差异统计基线。
