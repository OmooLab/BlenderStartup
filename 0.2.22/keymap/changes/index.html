    主要改动

    这里解释最影响日常操作的变化。它不是完整快捷键表，只帮助你快速建立正确的使用习惯。

    新增与融合

    两套导航方式并存

    Blender 原有的 MMB 导航完整保留，同时增加 ALT + LMB / MMB / RMB。无论习惯 Blender 还是其他 DCC，都可以直接控制视图。

    两套 Transform 方式并存

    保留 Blender 的 G / S / R 操作逻辑，同时加入 W / E / R Transform 工具。即时操作和工具操作可以按场景选择。

    同一种意图使用同一个键

    • F 聚焦所选，双击 F 查看全部
    • 点击 TAB，在 3D View 添加物体，在 Node Editor 添加节点
    • 拖动 TAB 打开 Mode Pie
    • 1 / 2 / 3 直接进入点、边、面组件，4 返回 Object Mode
    • SHIFT + TAB 切换吸附

    这些变化尽量跨 Editor 和 Mode 保持相同含义，减少需要单独记忆的规则。

    停用与让位

    为了让上面的高频操作成立，一些 Blender Default 绑定被停用或调整了入口。

    TAB 不再直接切换 Object/Edit Mode

    点击 TAB 让给 Add Menu；模式切换改为拖动 TAB 打开 Mode Pie，或使用 1 / 2 / 3 / 4 直接进入目标层级。

    A 不再作为主要的全选入口

    全选改为更通用的 CTRL + A，为其他上下文操作留出单键空间。

    R 的单击入口让给 Rotate Tool

    单击 R 选择 Rotate Tool；需要 Blender 式的即时旋转时使用双击 R。

    W 不再打开上下文菜单

    W 用于 Move Tool，上下文菜单统一由 RMB 打开。

    数字键不再控制 Collection 显隐

    1 / 2 / 3 / 4 用于更高频的组件与模式切换。原本冲突的 Collection 显隐绑定被停用。

    Node Group 不再使用 TAB 进入

    Node Editor 的 TAB 用于添加节点。双击节点组进入，按 ESC 退出。

    查找其他改动

    以上只说明最重要的变化。完整绑定、停用项目和版本差异可在快捷键完整参考中按功能查询。
